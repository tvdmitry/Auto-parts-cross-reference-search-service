# Подбор автозапчастей — Favorit Parts

Клиентское приложение на **React + Redux Toolkit**, JavaScript без TypeScript. Стили — Bootstrap и небольшой CSS-файл. Реализованы только поиск производителей по артикулу и получение предложений с аналогами после выбора производителя.

**Сайт:** [tvdmitry.github.io](https://tvdmitry.github.io/). **Исходный код:** [Auto-parts-cross-reference-search-service](https://github.com/tvdmitry/Auto-parts-cross-reference-search-service).

## Версия на GitHub Pages

На опубликованном сайте введите личный ключ покупателя в форме «Подключите поиск». После этого доступны оба этапа подбора. Ключ хранится только в памяти вкладки: он не включён в исходники, сборку, Redux, localStorage или sessionStorage. При перезагрузке страницы ключ нужно ввести заново; кнопка «Изменить ключ» удаляет его и очищает результаты.

GitHub Pages обслуживает статические файлы, поэтому эта версия вызывает HTTPS API Favorit Parts прямо из браузера. API возвращает разрешающий CORS-заголовок. Ключ передаётся в GET-параметре `key`, как требует API, и виден владельцу вкладки в её сетевых запросах. Общего встроенного ключа нет.

```powershell
npm run build:pages
npm run preview
```

Основной код хранится в этом репозитории. Репозиторий [tvdmitry.github.io](https://github.com/tvdmitry/tvdmitry.github.io) содержит workflow публикации: он забирает код из `main`, выполняет тесты, собирает Pages-версию и размещает её по корневому адресу. Для обновления сайта после изменения кода запустите **Actions → Deploy application to GitHub Pages → Run workflow** в репозитории `tvdmitry.github.io`.

## Запуск

Требуется **Node.js 22.12+** и ключ покупателя Favorit Parts.

В каталоге проекта:

```powershell
npm install
Copy-Item .env.example .env
```

Заполните `.env`:

```dotenv
FAVORIT_API_KEY=ваш_ключ_покупателя
```

```powershell
npm run dev
```

Откройте адрес из терминала, обычно **http://127.0.0.1:5173**. После изменения `.env` перезапустите сервер.

Без ключа интерфейс работает, но поиск показывает сообщение о необходимости настроить подключение. Демонстрационных данных и подмены реального ответа в приложении нет.

## Как работает поиск

1. После паузы в 500 мс при вводе артикула отправляется GET-запрос с `number` и серверным `key`. Из массива `goods` собирается список уникальных производителей.
2. При выборе производителя отправляется GET-запрос с `number`, `brand` и `analogues=on`.
3. Таблица показывает исходные товары и вложенные `goods[].analogues`. Для каждого склада создаётся отдельная строка: наименование, артикул, производитель, склад, остаток и цена.

Цена берётся **только из `warehouses[].price`**, остаток — из `warehouses[].stock`. Устаревшее поле `goods[].price` не используется. Для позиции без складских предложений выводятся отсутствие цены и общий остаток `count` (в том числе нулевой); отсутствующие значения не подменяются нулями. Цены отображаются в рублях.

При изменении артикула очищаются выбранный производитель и предыдущие результаты. Запросы отменяются через `AbortSignal`; Redux дополнительно проверяет `requestId`, чтобы запоздалый ответ не заменил актуальные данные.

Обработаны: загрузка обоих этапов, пустой ответ, пустая структура товара из документации, отсутствие предложений, ошибки ключа и лимита API, сетевые и HTTP-ошибки, неверный JSON, тайм-аут. Для ошибок есть повтор запроса.

## API и ключ в локальной серверной версии

Спецификация: [wsprice.pdf](https://lk.favorit-parts.ru/static/wsprice.pdf), версия от 06.03.2023.

Используется HTTPS-адрес `https://api.favorit-parts.ru/hs/hsprice/`. Параметры кодируются через `URLSearchParams`, включая `#`, `&`, `+` и пробелы.

Браузер вызывает `/api/price` на том же origin. Минимальный серверный прокси добавляет ключ и отправляет запрос Favorit Parts. Ключ не включается в JavaScript-сборку, Redux или браузерный URL. Не используйте префикс `VITE_` для ключа и не добавляйте `.env` в Git. При разработке и предпросмотре прокси подключён как middleware Vite; готовую сборку обслуживает небольшой Express-сервер с тем же middleware.

## Сборка и запуск готового приложения

```powershell
npm run build
npm start
```

Приложение доступно по адресу **http://127.0.0.1:3000**. `HOST` и `PORT` можно задать в `.env` или окружении процесса. Ключ также можно передать через окружение вместо `.env`.

`npm run preview` позволяет проверить сборку через Vite. Для постоянного размещения используйте `npm start` либо настройте `/api/price` на своём сервере. Простого размещения `dist` на статическом хостинге недостаточно: поиску нужен прокси с ключом. Сервер по умолчанию слушает только локальный интерфейс; управление публичным доступом и развёртывание не входят в этот проект.

## Проверка

```powershell
npm test
npm run build
```

Автоматические тесты проверяют контракт API, кодирование параметров, цены и остатки складов, аналоги, нулевые значения, ошибки, тайм-аут прокси и защиту Redux от устаревших ответов. Они используют тестовые ответы и не обращаются к аккаунту Favorit Parts. Для проверки реальных результатов требуется действующий ключ покупателя.
