# Подбор автозапчастей — Favorit Parts

Клиентское приложение на **React + Redux Toolkit**, JavaScript без TypeScript. Стили — Bootstrap и небольшой CSS-файл. Реализованы только поиск производителей по артикулу и получение предложений с аналогами после выбора производителя.

**Сайт:** [tvdmitry.github.io/search-service/](https://tvdmitry.github.io/search-service/). **Исходный код:** [Auto-parts-cross-reference-search-service](https://github.com/tvdmitry/Auto-parts-cross-reference-search-service).

## Версия на GitHub Pages

Поиск доступен сразу после открытия сайта. Введите артикул и выберите производителя. Приложение автоматически передаёт в обоих запросах публичный ключ из примеров `wsprice.pdf` (страница 3): `00000000-0000-0000-0000-000000000001`. Формы ввода ключа нет; перезагрузка страницы не требует дополнительной настройки.

GitHub Pages обслуживает статические файлы, поэтому эта версия вызывает HTTPS API Favorit Parts прямо из браузера. API возвращает разрешающий CORS-заголовок. Публичный ключ задан в `src/api/config.js` и передаётся в GET-параметре `key`. Результаты загружаются из реального сервиса, без подмены данных.

```powershell
npm run build:pages
npm run preview -- --mode pages
```

Основной код хранится в этом репозитории. Репозиторий [tvdmitry.github.io](https://github.com/tvdmitry/tvdmitry.github.io) содержит workflow публикации: он забирает код из `main`, выполняет тесты, собирает Pages-версию и размещает её в `/search-service/`. На корневом адресе приложение не размещается. Для обновления сайта после изменения кода запустите **Actions → Deploy application to GitHub Pages → Run workflow** в репозитории `tvdmitry.github.io`.

## Запуск

Требуется **Node.js 22.12+**. Ключ из PDF подставляется автоматически и в локальном режиме.

В каталоге проекта:

```powershell
npm install
npm run dev
```

Откройте адрес из терминала, обычно **http://127.0.0.1:5173**.

При необходимости использовать личный ключ в локальной серверной версии скопируйте `.env.example` в `.env` и замените значение:

```dotenv
FAVORIT_API_KEY=ваш_ключ_покупателя
```

После изменения `.env` перезапустите сервер. Эта настройка относится только к серверному режиму; Pages-версия использует публичный ключ из документации.

## Как работает поиск

1. После паузы в 500 мс при вводе артикула отправляется GET-запрос с `number` и автоматически добавленным `key`. Из массива `goods` собирается список уникальных производителей.
2. При выборе производителя отправляется GET-запрос с `number`, `brand` и `analogues=on`.
3. Таблица показывает исходные товары и вложенные `goods[].analogues`. Для каждого склада создаётся отдельная строка: наименование, артикул, производитель, склад, остаток и цена.

Цена берётся **только из `warehouses[].price`**, остаток — из `warehouses[].stock`. Устаревшее поле `goods[].price` не используется. Для позиции без складских предложений выводятся отсутствие цены и общий остаток `count` (в том числе нулевой); отсутствующие значения не подменяются нулями. Цены отображаются в рублях.

При изменении артикула очищаются выбранный производитель и предыдущие результаты. Запросы отменяются через `AbortSignal`; Redux дополнительно проверяет `requestId`, чтобы запоздалый ответ не заменил актуальные данные.

Обработаны: загрузка обоих этапов, пустой ответ, пустая структура товара из документации, отсутствие предложений, ошибки ключа и лимита API, сетевые и HTTP-ошибки, неверный JSON, тайм-аут. Для ошибок есть повтор запроса.

## API и ключ в локальной серверной версии

Спецификация: [wsprice.pdf](https://lk.favorit-parts.ru/static/wsprice.pdf), версия от 06.03.2023.

Используется HTTPS-адрес `https://api.favorit-parts.ru/hs/hsprice/`. Параметры кодируются через `URLSearchParams`, включая `#`, `&`, `+` и пробелы.

Браузер вызывает `/api/price` на том же origin. Минимальный серверный прокси добавляет ключ из PDF либо значение `FAVORIT_API_KEY`, если оно задано, и отправляет запрос Favorit Parts. Личный ключ из окружения не включается в JavaScript-сборку, Redux или браузерный URL. Не используйте префикс `VITE_` для личного ключа и не добавляйте `.env` в Git. При разработке и предпросмотре прокси подключён как middleware Vite; готовую сборку обслуживает небольшой Express-сервер с тем же middleware.

## Сборка и запуск готового приложения

```powershell
npm run build
npm start
```

Приложение доступно по адресу **http://127.0.0.1:3000**. `HOST` и `PORT` можно задать в `.env` или окружении процесса. Ключ также можно передать через окружение вместо `.env`.

`npm run preview` позволяет проверить серверную сборку через Vite. Для её постоянного размещения используйте `npm start` либо настройте `/api/price` на своём сервере. Для статического хостинга предназначена отдельная сборка `npm run build:pages` с прямыми запросами к API. Сервер по умолчанию слушает только локальный интерфейс.

## Проверка

```powershell
npm test
npm run build
```

Автоматические тесты проверяют подстановку ключа из PDF на обоих этапах, контракт API, кодирование параметров, цены и остатки складов, аналоги, нулевые значения, ошибки, тайм-аут прокси и защиту Redux от устаревших ответов. Они используют тестовые ответы и не обращаются к аккаунту Favorit Parts. Реальный поиск можно проверить с артикулом `01089` и производителем `ASAM`.
